Probability has a shape, but most textbooks hide it behind a formula. A normal is `exp(-(x-μ)²/2σ²)/√2πσ` until you drag σ and watch the bell flatten, or until you draw 1,000 samples and the histogram stops arguing. I wanted one place where that loop — *formula → picture → sample → fit* — is tight and honest, for 16 univariate distributions and for the multivariate, copula, and mixture machinery that real work actually needs. The result is **probviz**, a Streamlit explorer plus a typed Python library, now on PyPI as [`probviz`](https://pypi.org/project/probviz/) with [docs on GitHub Pages](https://sanskarpan.github.io/probviz/). Try it before you read on:

```bash

probviz app                  # opens the explorer on :8501

```

The [repo is on GitHub](https://github.com/sanskarpan/probviz). Everything below is `pip install probviz` importable, and the app is one command away.

## The loop you actually learn from

Statistics is not a list of PDFs. It is a loop: you posit a distribution, you look at it, you sample from it, you check whether your data looks like it, and you quantify how wrong you are. Most visualizers give you the second step and stop. Most libraries give you the last two and make you wire the pictures yourself. probviz keeps the four in one place with one API shape.

The invariant is small: every distribution is a `Distribution` with the same verbs — `pdf`/`cdf`/`ppf`/`rvs`/`mean`/`var`/`entropy`/`interval` — whether it is a Bernoulli or a Gumbel copula mix. The uniformity is the feature. If you can plot a normal, you can plot a mixture with the same call.

## 16 univariate distributions, with real parameter bounds

Ten continuous and six discrete, each a thin, validated facade over `scipy.stats`. The facade earns its keep: it binds the SciPy frozen distribution, exposes `get_parameters`/`get_parameter_bounds`/`set_parameters`, and validates ranges so a slider cannot silently put you at `σ = 0`.

```python
from src.distributions.continuous import NormalDistribution, BetaDistribution
from src.distributions.discrete import BinomialDistribution

n = NormalDistribution(mu=0, sigma=1)
n.pdf(0)          # 0.3989...
n.cdf(1.96)       # 0.975
n.ppf(0.5)        # 0.0
n.rvs(size=1000, random_state=0).mean()  # ≈ 0
n.interval(alpha=0.95)  # central 95% interval

b = BetaDistribution(alpha=2, beta=5)
b.pdf(0.5)
b.get_parameter_bounds()   # {'alpha': (0.1, 10), 'beta': (0.1, 10)}
```

| Continuous (10) | Discrete (6) |
|---|---|
| Normal `μ, σ`, Exponential `λ`, Uniform `a,b`, Beta `α,β`, Gamma `shape,scale`, Chi-Square `df`, Student-t `df`, Weibull `shape,scale`, Lognormal `μ,σ`, Cauchy `x₀,γ` | Binomial `n,p`, Poisson `λ`, Geometric `p`, Negative Binomial `r,p`, Hypergeometric `M,n,N`, Discrete Uniform `low,high` |

Every continuous entry caps its support honestly: the Cauchy reports `mean` → `nan` rather than pretending. Every discrete entry dispatches `pdf` → `pmf`. The contract is boring, and boring is portable.

## Multivariate, copulas, and the dependence you cannot see in one dimension

A multivariate normal is not “two normals.” It is a mean vector and a covariance whose off-diagonal is the dependence. probviz gives you four multivariate laws — `MultivariateNormalDistribution`, `DirichletDistribution`, `MultivariateStudentT`, `WishartDistribution` — each with `pdf`/`logpdf`/`rvs`/`mean`/`cov`/`marginal`/`conditional`/`mahalanobis`, plus two plotters that actually earn their import.

```python
from src.distributions.multivariate import MultivariateNormalDistribution

mvn = MultivariateNormalDistribution(mean=[0, 0], cov=[[1, 0.5], [0.5, 1]])
mvn.pdf([0, 0])
mvn.conditional(indices=[0], values={1: 1.0})  # Schur complement
mvn.rvs(size=10, random_state=0).shape  # (10, 2)
```

Copulas are where dependence lives after you have stripped the marginals. Four are implemented — `GaussianCopula`, `ClaytonCopula`, `GumbelCopula`, `StudentTCopula` — with the right guardrails: Clayton and Gumbel are bivariate-only for `pdf`/`rvs` and say so in an explicit `NotImplementedError`; Student-t documents `cdf`/`pdf` as intentionally unimplemented and offers Monte Carlo via `rvs` instead of inheriting a bare exception; `fit_copula_to_data` validates Kendall's τ ranges and documents its `df=4` simplification.

<Mermaid label="Fig 2" caption="A copula separates marginals from dependence — fit the rank correlation, then sample uniform pairs." chart={`

  R --> TAU["Kendall τ"]

```python
from src.distributions.copulas import GaussianCopula, fit_copula_to_data
import numpy as np

cop = GaussianCopula(correlation=np.array([[1, 0.5], [0.5, 1]]))
u = cop.rvs(n_samples=1000, random_state=0)   # reproducible via default_rng
u2 = cop.rvs(n_samples=1000, random_state=0)  # np.allclose(u, u2)

data = np.random.randn(200, 2)
fitted = fit_copula_to_data(data, copula_type="gaussian", method="rank")
```

Reproducibility is per-call (`np.random.default_rng(random_state)`), not global `np.random.seed` mutation — the mistake the audit removed.

## Mixtures: EM that does not lie about convergence

A mixture is `∑ wᵢ · pᵢ(x)`. The naive EM bug is checking convergence before the M-step and returning stale weights. probviz checks after the M-step, with guards for empty data, `n_components > n`, zero row-likelihoods, zero counts, and zero variance, plus a local RNG.

```python
from src.distributions.mixtures import MixtureDistribution
from src.distributions.continuous import NormalDistribution
import numpy as np

mix = MixtureDistribution(
    components=[NormalDistribution(mu=-2, sigma=1), NormalDistribution(mu=2, sigma=1)],
    weights=[0.5, 0.5],
)
mix.pdf(0.0)
mix.rvs(size=1000, random_state=0).shape  # (1000,)

# Or discover components from data:
from src.distributions.mixtures import GaussianMixtureModel, select_optimal_components

gmm = GaussianMixtureModel(n_components=2)
gmm.fit(data)
gmm.bic(data), gmm.aic(data)
select_optimal_components(data, max_components=6)  # BIC sweep → optimal k
```

## Fitting and model selection without hand-waving

`DistributionFitter` tries up to 10 laws (`norm`, `expon`, `gamma`, `beta`, `lognorm`, `weibull_min`, `t`, `chi2`, `uniform`, `cauchy`), fits each by MLE via `dist.fit`, and ranks by `AIC = 2k − 2LL` and `BIC = k log n − 2LL` with a KS `kstest` column. `BayesianEstimator` gives conjugate posteriors (Normal mean/variance, Poisson rate, Bernoulli p) and `GoodnessOfFit` wraps chi-square, KS, Anderson-Darling, Shapiro-Wilk, and Jarque-Bera with the SciPy 1.17 `method="interpolate"` nuance handled.

```python
from src.fitting.distribution_fitter import DistributionFitter
import numpy as np

data = np.random.gamma(shape=2, scale=2, size=500)
fitter = DistributionFitter(data)
table = fitter.fit_all()          # sorted by AIC, with KS p-values
best = table.iloc[0].name

# Bayesian update: prior N(0,1), known variance 1
from src.fitting.distribution_fitter import BayesianEstimator
post_mean, post_var = BayesianEstimator(data).estimate_normal_mean(
    prior_mean=0, prior_var=1, known_variance=1
)
```

The ranking is the point. Seeing Gamma beat Lognormal by 12 AIC on your actual data teaches more than any textbook table.

## Monte Carlo that is honest about variance

`MonteCarloSimulator` is seven methods around one loop — `simulate`, `estimate_probability` (Wilson interval), `estimate_expectation`, `importance_sampling` (with `ESS = (∑w)²/∑w²`), `stratified_sampling`, `bootstrap`, `permutation_test` — plus `VarianceReduction` (antithetic variates, control variates with optimal `β = Cov/Var`) and `QuasiMonteCarloSimulator` (Halton van der Corput, Sobol via `scipy.stats.qmc`).

```python
from src.monte_carlo.simulator import MonteCarloSimulator, VarianceReduction

sim = MonteCarloSimulator(random_seed=0)
res = sim.simulate(lambda: np.random.randn(), num_samples=10000, confidence_level=0.95)
res.mean, res.confidence_interval, res.quantiles[0.95]

# Variance reduction: antithetic pairs cut variance without more samples
mean, se = VarianceReduction.antithetic_variates(
    sampler=lambda n: np.random.rand(n),
    func=lambda x: np.exp(x),
    num_pairs=5000,
)
```

## Statistical tests that return dictionaries, not mysteries

Thirteen dict-returning helpers, JSON-friendly by design: `t_test`, `chi_square_test`, `anova`, `correlation_test`, `normality_tests` (consensus >50%), plus nonparametric `mann_whitney_u`, `wilcoxon_signed_rank`, `kruskal_wallis`, `friedman_test`, and descriptive `describe`/`quantile_summary`/`outlier_detection`/`correlation_matrix`. Each returns `p_value`, `reject_null`, and an `interpretation` string you can log without unpacking a SciPy result object.

```python
from src.statistical_tests.hypothesis_tests import t_test, normality_tests
from src.statistical_tests.descriptive import describe

a = np.random.normal(0, 1, 100)
b = np.random.normal(0.2, 1, 100)
t_test(a, b, alternative="two-sided")  # {'statistic','p_value','reject_null',...}
describe(a)  # count, mean, std, se, cv, iqr, skewness, kurtosis, ...
normality_tests(a)["consensus"]  # Likely normal if <50% of tests reject
```

## The explorer: one page, 16 distributions, no tabs for the advanced part

The Streamlit app at `web/app.py` is intentionally single-page + sidebar, not a tab farm. The sidebar is the only control surface: *Continuous vs Discrete* → distribution picker → sliders built from `get_parameters`/`get_parameter_bounds` → visualization toggles. The main column renders current parameters, four headline statistics (`Mean`, `Variance`, `Std Dev`, `Median`), three more (`Mode`, `Skewness`, `Excess Kurtosis`), and two cached plots — `plot_pdf_pmf` (Plotly Viridis bar / filled scatter with a red mean, green median) and `plot_cdf` — plus an optional large-sample histogram, a five-quantile row (`5, 25, 50, 75, 95` via `ppf`), and structured logging with a `correlation_id` per page view.

The honest footnote the docs repeat: the Streamlit explorer covers the 16 univariate distributions only. Multivariate, copulas, mixtures, fitting, Monte Carlo, and the test suite are Python-API only — the gallery GIFs (`normal_sigma_morph`, `clt_convergence`, `copula_dependence`, `beta_shape_morph`, `mixture_separation`, regenerable via `examples/generate_media.py`) are the pictures for those modules.

## Engineering that keeps it publishable

The library is `src`-layout, `setuptools`/`wheel`, `probviz` on PyPI `1.0.3` (`Python ≥3.10`, classifiers `3.10|3.11|3.12`), 10 runtime deps (`numpy`, `scipy`, `pandas`, `matplotlib`, `seaborn`, `plotly`, `streamlit`, `scikit-learn`, `statsmodels`, `joblib`), entry point `probviz = src.cli:main`, sdist/wheel shipping `src`+`web`+`tests` so `probviz test` works from a pip install. The CLI forwards `probviz app --server.port 8501` untouched (`parse_known_args` + `REMAINDER`, order preserved in `1.0.3`), locates `web/app.py` via `import web`, and `probviz test` degrades gracefully with `pip install "probviz[test]"`.
